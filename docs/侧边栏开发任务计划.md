## 技术说明

- **技术栈**：Vue 3 + JavaScript + Vite + 原生 CSS（CSS 变量做主题）
- **状态管理**：目前各视图独立 ref，建议引入 Pinia 统一管理会话/侧栏状态
- **数据来源**：会话列表走后端 `/api/sessions` 接口，WebSocket 实时推送更新
- **持久化**：侧栏折叠状态、主题等存 localStorage；会话数据存后端 SQLite
